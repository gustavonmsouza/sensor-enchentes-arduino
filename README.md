# Sistema Anti-Enchente com Arduino

## Descrição

Este projeto foi desenvolvido para monitorar o nível da água utilizando Arduino e sensores, auxiliando na prevenção de enchentes e no controle hídrico.

O sistema identifica automaticamente diferentes níveis de risco (normal, atenção e perigo) e aciona alertas visuais e sonoros para informar a situação em tempo real.

## Objetivo

Desenvolver um sistema automatizado capaz de monitorar áreas sujeitas a alagamentos, contribuindo para a prevenção de enchentes e para a segurança da população.

O projeto está relacionado ao Objetivo de Desenvolvimento Sustentável (ODS) 6 – Água Limpa e Saneamento.

## Tecnologias Utilizadas

* Arduino Uno
* Linguagem C++
* Tinkercad
* Sensor Ultrassônico HC-SR04
* Sensor de Umidade/Chuva
* Potenciômetro
* LEDs
* Buzzer
* Servo Motor

## Funcionalidades

* Monitoramento contínuo do nível da água;
* Detecção automática de situações de risco;
* Indicação visual por LEDs:

  * Verde: situação normal;
  * Amarelo: atenção;
  * Vermelho: perigo;
* Emissão de alerta sonoro por buzzer;
* Acionamento automático de uma comporta simulada por servo motor;
* Exibição de dados no Serial Monitor.

## Técnicas Implementadas

* Filtro de média móvel para reduzir oscilações das leituras do sensor;
* Calibração por potenciômetro;
* Rotina de teste dos componentes do sistema.
